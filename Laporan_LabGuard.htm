Penulis

ABSTRAK

Penggunaan internet yang tidak terkendali pada laboratorium komputer sekolah maupun perguruan tinggi kerap menjadi kendala dalam proses pembelajaran, karena siswa cenderung mengakses situs hiburan seperti media sosial, video streaming, dan permainan daring pada saat jam pelajaran berlangsung. Penelitian ini bertujuan untuk merancang dan membangun sebuah sistem manajemen laboratorium komputer terpusat bernama LabGuard Classroom Management yang memungkinkan pengajar memantau seluruh komputer siswa serta memblokir akses terhadap situs-situs tertentu secara real-time melalui satu dasbor web. Sistem dikembangkan dengan arsitektur client-server yang terdiri atas tiga komponen utama, yaitu: (1) aplikasi server berbasis Node.js dan Express yang menyediakan layanan REST API; (2) antarmuka dasbor guru berbasis React dan TypeScript; serta (3) program agent berbasis Python yang berjalan pada setiap komputer siswa. Mekanisme pemblokiran dilakukan dengan memodifikasi file hosts Windows secara otomatis, sehingga domain yang terdaftar pada blacklist dialihkan ke alamat lokal (127.0.0.1) dan tidak dapat diakses. Sinkronisasi status antara server dan agent dilakukan melalui mekanisme polling dengan interval lima detik. Hasil pengujian fungsional dengan metode black box menunjukkan bahwa seluruh fitur sistem berjalan sesuai dengan rancangan, meliputi pemantauan status komputer siswa, pengelolaan daftar blacklist, pemblokiran per komputer maupun menyeluruh, serta mekanisme pemulihan otomatis (self-healing) ketika koneksi ke server terputus. Sistem ini diharapkan dapat menjadi solusi praktis dan berbiaya rendah bagi institusi pendidikan dalam menciptakan lingkungan belajar berbasis komputer yang tertib dan terkendali.

Kata kunci: manajemen laboratorium komputer, pemblokiran situs, file hosts, client-server, REST API, React, Python.

1.1 Latar Belakang

Perkembangan teknologi informasi telah mendorong hampir seluruh institusi pendidikan untuk menyediakan laboratorium komputer yang terhubung dengan jaringan internet sebagai sarana penunjang pembelajaran. Kehadiran internet di ruang laboratorium memberikan kemudahan bagi siswa dalam mengakses sumber belajar, mengerjakan tugas praktikum, serta mengikuti pembelajaran berbasis daring. Namun demikian, akses internet yang terbuka tanpa pengawasan juga menimbulkan permasalahan tersendiri, yakni kecenderungan siswa untuk mengakses konten yang tidak berhubungan dengan materi pembelajaran, seperti media sosial, layanan video streaming, dan permainan daring pada saat jam pelajaran berlangsung.

Kondisi tersebut menyulitkan pengajar dalam mengendalikan jalannya kegiatan praktikum. Pengawasan secara manual dengan berkeliling ruangan tidaklah efektif, terutama pada laboratorium dengan jumlah komputer yang banyak. Di sisi lain, solusi komersial berupa perangkat lunak classroom management maupun perangkat keras firewall jaringan umumnya memerlukan biaya lisensi yang tidak sedikit dan konfigurasi yang kompleks, sehingga tidak semua institusi pendidikan mampu mengadopsinya.

Berdasarkan permasalahan tersebut, diperlukan sebuah sistem manajemen laboratorium komputer yang sederhana, berbiaya rendah, dan mudah dioperasikan oleh pengajar. Salah satu pendekatan teknis yang dapat dimanfaatkan adalah mekanisme resolusi nama domain lokal melalui file hosts pada sistem operasi Windows. Dengan menambahkan entri pemetaan domain ke alamat lokal (127.0.0.1), sebuah komputer dapat dicegah untuk mengakses situs tertentu tanpa memerlukan perangkat jaringan tambahan.

Atas dasar pemikiran itulah penulis merancang dan membangun sistem LabGuard Classroom Management, yaitu sistem manajemen laboratorium komputer terpusat berbasis web yang memungkinkan pengajar memantau status seluruh komputer siswa, mengelola daftar situs terlarang (blacklist), serta mengaktifkan dan menonaktifkan pemblokiran secara real-time dari satu dasbor. Sistem ini memadukan aplikasi server berbasis Node.js dan Express, antarmuka web berbasis React dan TypeScript, serta program agent berbasis Python yang berjalan pada setiap komputer siswa.

1.2 Rumusan Masalah

Berdasarkan latar belakang yang telah diuraikan, rumusan masalah dalam penelitian ini adalah sebagai berikut:

  1. Bagaimana merancang dan membangun sistem manajemen laboratorium komputer terpusat yang memungkinkan pengajar memantau seluruh komputer siswa melalui satu dasbor web?
  2. Bagaimana menerapkan mekanisme pemblokiran situs pada komputer siswa secara real-time dengan memanfaatkan modifikasi file hosts Windows?
  3. Bagaimana menjamin sinkronisasi status antara server pada komputer guru dan agent pada komputer siswa, serta pemulihan otomatis apabila koneksi terputus?

1.3 Batasan Masalah

Agar pembahasan lebih terarah, penelitian ini dibatasi pada hal-hal berikut:

  1. Sistem dirancang untuk digunakan pada jaringan lokal (LAN) laboratorium komputer, dengan satu komputer guru sebagai server dan sejumlah komputer siswa sebagai klien.
  2. Mekanisme pemblokiran diimplementasikan melalui modifikasi file hosts pada sistem operasi Windows, sehingga agent memerlukan hak akses Administrator.
